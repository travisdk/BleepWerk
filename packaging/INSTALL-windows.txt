BleepWerk – installation on Windows
====================================

The archive contains BleepWerk in two plug-in formats, CLAP and VST®3.
Install the one your DAW uses, or both.

For your user only (no administrator rights needed):

    CLAP:  copy BleepWerk.clap to   %LOCALAPPDATA%\Programs\Common\CLAP\
    VST3:  copy the BleepWerk.vst3 folder to   %LOCALAPPDATA%\Programs\Common\VST3\

For all users (needs administrator rights):

    CLAP:  C:\Program Files\Common Files\CLAP\
    VST3:  C:\Program Files\Common Files\VST3\

Create the folder if it does not exist, then restart your DAW or rescan
plug-ins. BleepWerk appears as an instrument.

If the BleepWerk window looks blurry, is the wrong size or is cut off when
Windows display scaling is above 100 %, your DAW is probably stretching the
plug-in window. BleepWerk scales itself, so turn that DAW setting off for
BleepWerk. In Ableton Live: right-click BleepWerk in the browser and untick
"Auto-Scale Plug-in Window", then reopen the plug-in.
